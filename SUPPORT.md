# Support

`watchd` is an early project maintained on a best-effort basis. There are no stability, response-time, compatibility, or production-support guarantees.

- Use GitHub issues for reproducible bugs and accepted feature proposals.
- Use the issue templates and search for duplicates before opening a new issue.
- Do not use public issues for vulnerabilities; follow [SECURITY.md](SECURITY.md).
- General PostgreSQL, Go, or Kubernetes support requests are outside the project's scope unless they reveal a `watchd` defect or documentation gap.

Commercial support is not currently offered.
